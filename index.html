Alur kerja otomatis

1. Buat proyek → 2. Susun scene & prompt → 3. Pilih akun Flow → 4. Buka Flow dan generate manual → 5. Impor klip → 6. Gabungkan & ekspor.

PWA ini mengotomatiskan perencanaan, prompt, antrean, pencatatan akun, dan penggabungan klip. Interaksi Generate tetap dilakukan di situs resmi Flow. Jangan masukkan password atau kode keamanan akun ke aplikasi ini.

Catatan ekspor

Penggabungan menggunakan FFmpeg WebAssembly dari CDN dan memproses video di browser. Untuk menjaga kompatibilitas, versi awal mengekspor video tanpa audio. Klip panjang/resolusi tinggi bisa kehabisan memori di HP; coba klip pendek atau resolusi lebih rendah bila gagal. File asli tidak diubah.
